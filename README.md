# NFL Game Prediction — Machine Learning Learning Project

## Overview

This repository documents my introduction to machine learning using Python.

The goal of this project is to explore whether historical NFL team and game statistics can be used to predict the outcome of an NFL game.

This is primarily a **learning project**, rather than an attempt to build a professional sports prediction or betting model. I am using the project to develop my understanding of machine learning concepts while applying skills I have been developing in Python, pandas, data analysis, and Git/GitHub.

The project will be built incrementally, with each stage focusing on a different machine learning concept or part of the data-science workflow.

---

## Project Question

> **Can historical NFL statistics be used to predict which team will win an NFL game?**

The initial model will focus on relatively simple statistics and will become more sophisticated as I learn more about machine learning.
